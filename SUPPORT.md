## Asking a question

1. Search [existing issues](https://github.com/lazylib/request/issues)
   and [discussions](https://github.com/lazylib/request/discussions) first.
2. If you don't find an answer, open a new **Question** issue using the
   provided template.
3. For "is X a good fit?" type questions, also see the
   [When NOT to use](README.md#when-not-to-use) section of the README —
   it covers the most common cases.

## Filing a bug

Use the **Bug report** issue template. Include:

- a minimal reproduction
- your `go version`
- the package version (commit SHA or tag)

## Commercial support

This is a community-maintained package. No commercial support is
offered. If you need an SLA, vendor this package, fork it, or pick a
commercial alternative such as an API gateway / SDK generator for your
specific API.
